# WakeUp

A premium Android launcher and device-customization ecosystem, designed first for the Samsung Galaxy S25 Ultra, with a separate, genuinely native iPadOS companion planned.

Built around **Theme DNA**: one coherent system for wallpaper, motion, typography, widgets, icons, sound, haptics and device context.

Status: design specification stage. No code yet.
